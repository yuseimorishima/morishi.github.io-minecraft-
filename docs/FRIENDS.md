# 2人で同じワールドを遊ぶ

1. 招待する人が公開リンクでゲームを始めるか、保存した世界を読み込みます。
2. 「友達と遊ぶ」で名前を入れて「招待リンクを作る」を押し、コピーして友達へ送ります。
3. 友達がリンクを開き「参加する・返信コードを作る」を押します。
4. 友達が表示された返信コードをコピーし、招待した人へ送ります。
5. 招待した人が返信コードを貼り「返信コードで接続する」を押します。
6. 相手の名前と四角いキャラクターが見えたら、一緒に遊べます。接続画面は✕で閉じます。

採掘・配置・線路・チェスト・時刻を共有します。所持品、装備、体力、かまどの精錬は各プレイヤーに保持します。相手の持ち物を複製しません。招待した側が地形の変更を確定し、同時変更の衝突では参加側の素材と耐久度を戻します。接続中も各自で「保存」できます。読込は切断してから行います。

モンスターの移動・体力を招待側から共有し、近いプレイヤーを追跡します。参加側の攻撃・被ダメージも通信します。チャットは接続画面にあります。

## 接続の条件

WebRTC対応ブラウザ、インターネット接続、開いたままの招待側タブが必要です。2人用で、招待リンクはその接続だけに使えます。永続ルーム、常設サーバー、自動再接続はありません。同じWi-Fiでの利用が適しています。回線のNATやブラウザ設定によって直接接続できない場合があります。TURNリレーサーバーは設置していません。

通信を開始した際だけGoogle／CloudflareのSTUNを使い、接続候補を取得します。通常の1人プレイでは外部通信を開始しません。通信メッセージは最大8Mi文字で分割・順序検証・送信量調整を行い、過大なワールドでは接続を終了します。

## 検証の範囲

このクラウドのChromiumには `WebRtcIPHandling=disable_non_proxied_udp` という管理設定があり、接続候補を取得できませんでした。その設定は変更していません。実際の端末間WebRTC接続は未検証です。

`node tests/friends-browser.cjs` は、テスト専用の接続代替を使って2つの独立したブラウザ環境をつなぎます。製品の招待コード、メッセージ分割、初期ワールド、アバター、採掘・建築、同時変更の巻き戻し、共有チェスト、チャット、保存・切断を確認します。代替の通信は配布HTMLに含まれません。`node tests/friends.mjs` は接続コード、巨大メッセージ、無効な順序、座標の検証を確認します。
