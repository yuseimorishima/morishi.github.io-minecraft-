# BLOCK COASTER — Caves & Crafting

ブロックの山岳世界で木や鉱石を採掘し、道具・建物・レールを作る一人称HTMLゲーム。地面を掘って枝分かれする洞窟を探し、自分で作った地下鉄道に乗れます。独自のドット絵とゲームコードを使っています。Minecraft公式製品ではありません。

**[ブラウザで遊ぶ](https://yuseimorishima.github.io/morishi.github.io-minecraft-/)**

`index.html` だけをブラウザで開いても遊べます。ゲーム・CSS・Three.js・テクスチャを含む単体HTMLなので、サーバーや実行中の外部通信は不要です。WebGL対応ブラウザを使ってください。

## ワールドと遊び

- 64×64マス、高度−48〜63の編集可能なブロック世界。雪山、草原、採れる木、砂のある池。
- 高低差のある坑道が分岐し、地下37マス付近まで複数の大洞窟が続きます。岩棚・岩柱・石炭・鉄・金・小さなアメジストの鉱床があります。地上に洞窟入口は開いておらず、遺跡の下を掘って発見します。
- 山小屋、見張り塔、遺跡。小屋の中の作業台・かまど・チェストも利用できます。
- 36枠の持ち物、9枠のホットバー、64個までのスタック、道具の耐久度。
- 手元の2×2クラフトと、作業台の3×3クラフト。素材を手動で並べたり、レシピ一覧から自動で並べたりできます。
- 木・石・鉄のツルハシ、斧、シャベル。それぞれ適したブロックを早く掘れます。石は木以上、鉄は石以上、金は鉄のツルハシで回収。
- かまどで鉄・金・ガラスを精錬。原料1個と燃料1個を消費して4秒で完成。複数個を予約できます。燃料は石炭・原木・木材。
- チェスト27枠、配置できる松明、ガラス、木材や丸石の建築。
- サバイバルでは素材を消費し、落下で体力が減ります。りんごで体力と満腹度を回復。昼夜も変化します。大きな落下で体力がなくなると持ち物を持ったまま地上へ戻ります。
- クリエイティブでは持ち物画面の素材一覧から自由に取得でき、配置の消費なし。飛行も可能です。
- レールは最初0本。素材から製作し、地形に合わせて1本ずつ接続。乗車中も自由に見回せます。

## 最初の遊び方

1. 木の幹を左クリック長押しで採掘。Iで原木から木材、木材から棒と作業台を作る。
2. 作業台をホットバーに移し、選択してEで設置。近くでFを押して木のツルハシを作る。
3. 石を掘って丸石を集め、石のツルハシとかまどを作る。石炭から松明も作ろう。
4. 「地鳴りの遺跡」の下を階段状に掘り、坑道と洞窟を探す。鉄の原石を集め、かまどで鉄に焼く。
5. 作業台で鉄6個＋棒1本→レール16本。地上と洞窟をつなぎ、「乗る」で試乗。

木材4個で作業台、丸石8個でかまど、木材8個でチェスト。レシピ一覧に必要な素材を表示します。鉱石を素手で狙った場合は、回収に必要な道具を案内します。

## 操作

| 操作 | 内容 |
| --- | --- |
| ↑↓←→ | 視線を基準に前後左右へ移動 |
| マウス / スマホの画面ドラッグ | 見回す |
| Space / Shift | ジャンプ / 走る |
| 1〜9 / マウスホイール | ホットバーを選択 |
| E / 右クリック | 手持ちを配置。素手・道具なら1ブロック採掘 |
| 左クリック長押し | 採掘。持ち物がブロックでも掘れる |
| I / C | 持ち物と2×2クラフトを開く・閉じる |
| F | 狙った作業台・かまど・チェストを使う。近くの作業台も利用可能 |
| Q | 最後のレールを回収 |
| R | 地上へ帰る。持ち物と地形は保持 |
| V | クリエイティブで飛行切替。Space上昇・Shift下降 |
| Esc | 持ち物を閉じる / マウスを解除 |

持ち物の移動は、元の枠と移動先をクリック。クラフト欄には1個ずつ置きます。レシピのクリックで素材を自動配置し、完成品をクリックして製作します。Shift＋持ち物クリックでチェストに一括保管。「捨てる」はクリックで選択したスタックを削除します。

配置・採掘は8マスまで。レールは最後のマスの前後左右、高低差1マス以内に接続します。支持する床と頭上2マスの空間が必要です。レールの土台は先にQで線路を外してから掘れます。岩盤は掘れません。スマホには移動・ジャンプ・採掘・E配置ボタンがあります。

## 保存と共有

保存・読込ボタンで、地形・線路・持ち物・道具の耐久度・チェスト・精錬の予約・体力・昼夜・現在地をそのブラウザに保存します。自動保存ではないため、終了前に保存してください。HTMLを送っても個人の保存データは共有されません。

地形と素材の仕組みを変更したため、新版は新しいワールドとして始まります。旧版の保存キーを削除・上書きしません。旧データは新版には読み込めません。

友だちには上の公開URLか `index.html` を送ってください。公開手順は [SHARE.md](SHARE.md) にあります。

## 開発と検証

`game.js`、`style.css`、HTMLの画面構造を編集し、次を実行します。

```sh
python3 scripts/build_html.py
python3 -m http.server 8000
```

ビルドはPython標準ライブラリのみ。起動は静的HTMLのみ。Three.js 0.160.1のMITライセンスを `vendor/THREE-LICENSE.txt` と生成HTML内に含めています。

`tests/` はPlaywrightとChromiumを使うブラウザテストです。Playwrightを導入した環境で、静的サーバーを起動して実行します。`CHROMIUM_PATH` と `GAME_URL` でブラウザと確認先を指定できます。

```sh
node tests/progression.cjs
node tests/interactions.cjs
node tests/coaster-route.cjs
```

素材の採掘からクラフト・精錬・敷設・試乗・保存まで、手動クラフト、チェスト、4方向移動、スマホ画面、破損データの拒否、単体HTMLと地下への試乗を確認します。テストでは移動の時間を短縮するため、有効な保存データで現在地を移します。採掘や製作は画面とゲームの入力を通して実行します。

ブロックの編集は周囲のチャンクだけを再描画し、松明の光は近くの4本を描画します。有限の単一ワールド用のゲームで、流体の拡散、モンスター、マルチプレイ、第三者のMinecraftデータとの互換性はありません。
