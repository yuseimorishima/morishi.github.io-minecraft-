# BLOCK COASTER — Endless Biomes & Equipment

木や鉱石を採掘し、装備・建物・レールを作って、地上と洞窟を結ぶ一人称HTMLゲームです。移動した先の地形を生成し、最初の64×64マスから周囲のバイオームへ歩いて探索できます。独自のゲームコードと画像を使う非公式ゲームで、Minecraft公式製品ではありません。

**[ブラウザで遊ぶ](https://yuseimorishima.github.io/morishi.github.io-minecraft-/)**

`index.html` だけをWebGL対応ブラウザで開いても遊べます。ゲーム、CSS、Three.js、アイテム画像のPNGを単体HTMLへ埋め込んでおり、1人プレイでは実行中の外部通信やサーバーは不要です。友達との接続時のみWebRTCとSTUNを利用します。

## ワールド

- 水平方向は移動先を生成する方式です。64×64マスを1地域とし、その外側にも地形・洞窟・鉱脈・構造物が続きます。高度は−64〜111マスです。
- 平原、森林、砂漠、タイガ、雪山、ジャングル、赤砂の高原、海岸・海の8バイオーム。針葉樹、ジャングルの木、サボテン、キノコ、雪や氷も採掘できます。
- 地下の坑道は地域をまたいでつながり、枝道、大洞窟、岩棚、深部の水や溶岩の池が生成されます。最初の遺跡の下の洞窟は、引き続き掘って発見できます。
- 石炭、鉄、金、銅、ダイヤモンド、エメラルド、レッドストーン、ラピスラズリ、アメジスト。深さによって鉱脈の種類が変わり、複数ブロックの鉱脈を採掘できます。
- 小さな村、砂漠の神殿、密林の苔石遺跡、氷雪の小屋、海岸の難破船、山の展望塔、地下の廃坑。入口、内部の部屋、作業場、宝箱などを用意しています。最初の山小屋、見張り塔、地鳴りの遺跡も残っています。
- Mで探索地図を開くと、発見した地域、バイオーム、構造物、現在地と向きを確認できます。未探索の地域は暗く表示します。

構造物は一般的な種類を手掛かりに、このゲーム向けに独自設計しています。指定されたYouTubeチャンネルの特定と動画の取得は、環境のアクセス制限で完了していません。確認状況と設計案は [docs/STRUCTURE_REFERENCES.md](docs/STRUCTURE_REFERENCES.md) に記録しています。

## 装備・クラフト・画像

- 36枠の持ち物、9枠のホットバー、最大64個のスタック。道具と装備は耐久度を持ちます。
- 木、石、鉄、金、ダイヤモンド、エメラルドの6素材から、ツルハシ・斧・シャベル・剣を製作できます。素材と道具の種類によって採掘速度、耐久度が変わります。素手でも岩盤以外の石・鉱石を採掘でき、ツルハシを使うと速く壊せます。剣は葉やキノコを速く切るほか、モンスターへの攻撃にも使えます。
- 木、鉄、金、ダイヤモンド、エメラルドの5素材に、ヘルメット・胸当て・レギンス・ブーツがあります。頭・胴・脚・足・左手の5装備枠と盾を用意し、防御と耐久度を持ちます。
- 76件のクラフトレシピと8種類の精錬。建材、鉱物ブロック、レール、松明、盾、食料、本棚、コンパス、時計、地図などを作れます。原木や燃料の違いによるレシピも件数に含みます。
- レシピ一覧は、現在の素材で作れるものだけを表示します。手元は2×2、作業台では3×3のクラフトを使えます。必要な素材が足りないレシピや、そのクラフト欄に収まらないレシピは一覧へ出しません。
- レシピのクリックで材料を自動配置し、完成品をクリックして製作します。素材を手動で並べる方法も使えます。
- かまどでは鉄・金・銅・ガラス・レンガ・木炭・滑らかな石・焼きりんごを精錬します。1個4秒、石炭・木炭1個で8個分を精錬でき、燃料の残量を保持します。原木・木材も燃料に使えます。
- チェストは27枠。自然生成の宝箱から素材を見つけられます。空にした宝箱へ入手品を繰り返し補充しません。
- ChatGPTの画像生成で新規制作した104種類のアイテム画像を、道具、防具、鉱物、建材、食料の表示へ実装しています。画像と対応表は [assets/README.md](assets/README.md) にあります。

紙や本など、一部のレシピはこのゲーム独自の材料を使います。Minecraftのワールドやアイテムを読み込む互換機能はありません。

## 夜のモンスターと松明

- 1日は10分。夜は近くの暗い足場にゾンビとスライムが現れ、地形を歩いてプレイヤーを追跡・攻撃します。近くには最大6体。遠くへ離れた個体は解放します。
- 明かりを遮る壁がない松明の周囲9マスには出現しません。既存の敵も明かりから離れ、松明の明かりが届くプレイヤーへは攻撃しません。構造物にある松明にも同じ効果があります。
- 左クリック・画面長押し、または道具を持ってEで攻撃。剣などの攻撃力、装備の防御、道具の耐久を反映します。壁越しや離れた敵へは攻撃できません。
- 朝は直射日光にいる敵が弱り、消えます。屋根や地形の下では日光を避けます。クリエイティブと乗車中には攻撃されません。
- モンスターの位置は保存対象にせず、読込後は周囲の夜の条件から再出現します。時刻・設置した松明・討伐数は保存します。
- スマホは指を動かさず350ms押すと、その位置で採掘・攻撃が始まります。ドラッグすると見回しに切り替わり、指を離すと採掘は中断します。

## 最初の遊び方

1. 木の幹を左クリック長押しで採掘。Iで原木から木材、木材から棒と作業台を作ります。
2. 作業台をホットバーに移し、選択してEで設置。近くでFを押して木のツルハシを作ります。
3. 石から丸石を集め、石のツルハシとかまどを作ります。石炭や木炭と棒から松明を用意します。
4. 遺跡の下を階段状に掘るか、周囲のバイオームへ進んで洞窟や構造物を探します。鉄を精錬して、鉄のツルハシで深い鉱脈を速く採掘します。
5. 装備を作り、インベントリの部位に着けます。Shift＋持ち物クリックでも、その部位に合う装備を着けられます。
6. 作業台で鉄6個＋棒1本からレール16本を製作。地上と洞窟を1本ずつ結び、「乗る」で自分のコースに試乗します。

レールは最初0本です。地形を採掘・建築して床を整え、最後のレールの前後左右、高低差1マス以内に接続します。床の支持と頭上2マスの空間が必要です。乗車中も自由に見回せます。

## 操作

| 操作 | 内容 |
| --- | --- |
| WASD / ↑↓←→ | 視線を基準に前後左右へ移動 |
| マウス / スマホの画面ドラッグ | 見回す |
| Space / Shift | ジャンプ / 走る |
| 1〜9 / マウスホイール | ホットバーを選択 |
| E / 右クリック | 手持ちを配置・使用。素手や採掘道具なら採掘 |
| 左クリック / 画面長押し | 採掘・近くのモンスターへの連続攻撃 |
| I / C | 持ち物と手元のクラフトを開く・閉じる |
| F | 狙った作業台・かまど・チェストを使う。近くの作業台も利用可能 |
| M | 探索地図を開く・閉じる |
| Q | 最後のレールを回収 |
| R | 最初の地上拠点へ戻る。持ち物と地形は保持 |
| V | クリエイティブで飛行切替。Space上昇・Shift下降 |
| Esc | 画面を閉じる / マウスを解除 |

持ち物の移動は元の枠と移動先をクリック。クラフト欄へは1個ずつ置きます。Shift＋クリックでチェストへ一括保管できます。防具は部位の枠へ移すか、チェスト以外でShift＋クリックして着けます。「捨てる」は選択したスタックを削除します。スマホには移動・ジャンプ・採掘・E配置ボタンがあります。

画面の「描画距離」で周囲の描画範囲を変えられます。地形の表示は近くから順番に進みます。重い場合は距離を下げてください。クリエイティブでは持ち物画面の素材一覧からアイテムを取得でき、配置で素材を消費しません。

## 保存と共有

保存・読込ボタンで、編集した地形、線路、持ち物、装備、耐久度、チェスト、精錬の予約と燃料、探索地図、体力、昼夜、現在地をそのブラウザへ保存します。自動保存ではないため、終了前に保存してください。別の人へHTMLを送っても個人の保存データは共有されません。

前版v5の保存があり、新版v6の保存がない場合は、「読込」で地形、線路、持ち物、チェストなどを新しい座標方式へ移行します。旧版の保存キーは削除せず残します。さらに古いv4以前の保存は移行の対象外です。

友だちには公開URLか `index.html` を送ってください。公開手順は [SHARE.md](SHARE.md) にあります。

## 開発と検証

ソースは `game.js`、`mining.js`、`monsters.js`、`world.js`、`legacy-world.js`、`items.js`、`art.js`、`save.js`、`style.css` とHTMLの画面構造です。

```sh
npm run build
python3 -m http.server 8000
npm test
```

ビルドはPython標準ライブラリのみ。起動は静的HTMLのみです。`npm test` はNode.js標準機能で、地形の再現性と境界、鉱脈・バイオーム・構造物、アイテムとレシピ、保存の検証とv5移行、採掘速度、夜の出現条件、追跡・戦闘・松明の効果を調べます。Three.js 0.160.1のMITライセンスを `vendor/THREE-LICENSE.txt` と生成HTML内に含めています。

ブラウザテストはPlaywrightとChromiumを使います。静的サーバーを起動し、Playwrightを利用できる環境で次の8本を実行します。`CHROMIUM_PATH` と `GAME_URL` でブラウザと確認先を指定できます。

```sh
node tests/progression.cjs
node tests/interactions.cjs
node tests/coaster-route.cjs
node tests/equipment-browser.cjs
node tests/streaming-browser.cjs
node tests/navigation-fuel-loot.cjs
node tests/foliage-browser.cjs
node tests/night-controls.cjs
```

採掘・クラフト・精錬・試乗、持ち物とチェスト、装備とレシピ表示、スマホ画面、旧64マス境界を越える4方向移動、遠方のバイオーム、長距離移動中の描画・生成キャッシュ、帰還後の編集と保存を検証します。テストでは移動時間を短縮するため、有効な保存データで現在地を移す場合があります。配置・製作・持ち物操作と連続移動はゲームの入力を通して実行します。

描画は16×16マスのチャンクに分け、周囲を順番に生成・再描画します。離れた描画メッシュを破棄し、生成済みのブロックキャッシュは最大180チャンクに制限します。地形の編集、持ち物、宝箱などの永続データは別に保持するため、戻ると復元できます。流体の拡散やマルチプレイはありません。

### 地形画像と歩行判定

ChatGPTで生成した16種類の地形テクスチャを内蔵。草・石・木・葉などの模様を更新しました。
歩行では足元・頭上・壁を同じ体幅で判定するため、ブロックの端で落下してめり込むことを防ぎます。1ブロックの段差も自動では登れません。Space（スマホはジャンプボタン）で登ってください。
歩行の回帰確認: ローカルHTTPサーバーを起動して `node tests/walking.cjs`。段差のジャンプ、壁、頭上、ブロック端、着地をブラウザで確認します。

## 友達との冒険と操作感

- 「友達と遊ぶ」で2人用の招待リンクを作り、友達からの返信コードで接続できます。地形・線路・チェスト・時刻を共有し、相手の名前とキャラクターを表示します。持ち物は各自に保持し、同時採掘の衝突では素材と耐久度を戻します。
- 夜のモンスターは近い方のプレイヤーを狙います。接続画面からチャットもできます。
- 足音、木・石の採掘音、配置音、クラフト音などを合成音声で生成します。「操作」の「音 ON/OFF」で切り替えられます。
- 採掘で四角い破片が飛び散り、歩くと視点が小さく揺れ、走ると視野が広がります。四角い太陽と月、160個の星を追加しました。段差は引き続きジャンプ必須です。

接続は直接通信方式で、回線によって利用できません。端末間の実接続はクラウドブラウザの管理設定により未検証です。通信を再現した2ブラウザの同期テストを実施しています。手順と検証範囲は [友達と遊ぶ](docs/FRIENDS.md) を参照してください。
