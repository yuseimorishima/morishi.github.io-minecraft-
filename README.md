# BLOCK COASTER — 地底への冒険

大きな雪山や構造物のあるブロック世界を一人称で探索し、地面を掘って隠された大洞窟を発見。自分で敷いたレールで地下へ試乗するHTML/WebGLゲームです。Minecraft公式製品ではありません。

## 遊ぶ・友だちに渡す

`index.html` だけをブラウザで開けば遊べます。CSS、ゲームコード、Three.jsはHTML内に入っているため、サーバー・インストール・実行中の外部通信は不要です。WebGL対応ブラウザを使ってください。

友だちには `index.html` をファイルとして送れます。Webページとしてリンクを共有する公開手順は [SHARE.md](SHARE.md) にあります。

## 今回のワールド

- 64×64ブロックの世界。高度約50ブロックの雪山と、大きな高低差があります。
- 地下24ブロック付近に、約550マス・天井まで約20ブロックの大洞窟が隠れています。山頂からは70ブロック以上下です。結晶、地底湖、鍾乳石があります。
- 洞窟には最初から開いた入口がありません。「地鳴りの遺跡」の中央を掘り進めると地下へ到達できます。
- 地下の北側には下りの岩棚があり、レールを敷いて奥へ進めます。地上からは階段状に掘り、1段ずつレールをつなぐのがおすすめです。
- 中に入れる山小屋、らせん階段の見張り塔、掘削の目印になる遺跡があります。木材や石で自分の建物・橋も作れます。
- 最初のレールは0本。「掘削 → 洞窟発見 → 地上から接続 → 試乗」を目指します。

## 操作

| 操作 | 内容 |
| --- | --- |
| ↑↓←→ | 向いている方向を基準に移動 |
| マウス / スマホでは画面ドラッグ | 自由に見回す |
| Space / Shift | ジャンプ / 走る |
| 1 / 2 / 3 / 4 / 5 | レール / 土 / 掘削 / 木材 / 石 |
| E（左クリックも可） | 選んだ道具で配置または掘削 |
| Q / 右クリック | 末尾のレールを戻す |
| R / 「地上へ」 | 地上に帰る。地形と線路は残る |
| Esc | マウスを解除。ゲーム画面をクリックで再取得 |

狙える範囲は8ブロック。掘削は地面だけでなく壁や天井にも使えます。土・木材・石は、狙ったブロックに接する空きマスに置けます。自分の体やレールに重なる位置には置けません。

レールは最後のマスの前後左右へ、高低差1ブロック以内でつなぎます。床の支持と頭上2マスの空間が必要です。最下層、結晶や木の土台、レールを支えるブロックは掘れません。穴から出られなくなったらRを押してください。

「乗る」で試乗し、終点では折り返します。乗車中も自由に見回せます。「降りる」で編集へ戻れます。スマホには矢印・ジャンプ・配置のボタンがあります。

## 保存

保存・読込は、掘った地形、建築したブロック、線路、現在地、発見記録をそのブラウザに保管します。友だちにHTMLを送っても保存データは共有されません。前の洞窟ワールドの保存は別のキーで残りますが、この山岳ワールドには読み込めません。

## 開発

`game.js` と `style.css` を変更したら `python3 scripts/build_html.py` で単体HTMLを再生成します。`python3 -m http.server 8000` でローカル確認もできます。ビルド時の追加パッケージは不要です。

ブロック地形は編集した部分を再描画します。レールは直線・直角接続の簡易モデルで、三人称視点は今回の対象に含まれません。

Three.js 0.160.1のMITライセンスは `vendor/THREE-LICENSE.txt` と生成HTML内に含まれます。
